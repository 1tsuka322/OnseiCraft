# 用户指定的统一字幕规范（优先级最高，统计结果不得与之冲突）
# 这批语料来自多位译者，风格并不一致，以下规范是最终统一标准。

- **句内分隔一律用空格，不要用逗号**：如「那个…没事吧？」「啊 对不起 你别害怕…」，
  不要写成「那个，没事吧？」。只有列举长句时才可酌情用逗号。
- **语气延长、拖音、犹豫、语塞用三点「…」**（不是六连点「……」，也不是英文「...」）。
- **句末用句号「。」收束**（2026-10-08 用户改判；2026-10-09 复核后确认保留此规范）。
  理由：`cleanup()` 里「逗号/顿号 → 空格」的抹除机制仍然生效，若规范改成「不加句号」，
  模型会改用逗号收束，这些逗号随即被抹成空格 → 回到「标点全没了只剩空格」的机械感。
  语料统计只有 2% 句末带句号，那是旧「无句号」时代人工稿的产物，**不作为目标**。
  具体：陈述句句末用「。」；疑问句用「？」；感叹用「！」；拖音用「…」。
- **疑问句必须译出疑问语气，句末用「？」**。这是最容易出错的地方：
  Whisper 识别出的日文常常不带「？」，导致疑问句被当成陈述句翻译。
  判定依据（有其一即按疑问句处理）：
    · 句末助词 か / かな / かしら / の / ん / っけ / よね / でしょ / でしょう / ですか / ますか
    · 句中有 何 / なに / なん / どう / いつ / どこ / 誰 / だれ
    · 上下文明显是在发问、反问、确认（「〜でしょ？」「〜じゃない？」）
    · 句末是上升语调的「の？」「のかな？」
  注意区分：反问、确认（「そうでしょ？」）也是疑问；单纯的感叹（「すごい！」）不是。

## 拟声词：一律译成中文拟声词，绝不音译假名（2026-10-14 用户抽检后追加）

音声作品里**独立成句的短片假名拟声**最容易出错——上一轮试点实测把「キュー（亲吻声）」
音译成了「基欧」，把「カヤマヤマ」音译成「卡雅玛雅」。这类都要按中文拟声词译。

- 判据：一个片假名短词如果表示**声音**或**动作**，中文就用拟声词或动作词，
  **不要按音节拼成汉字**。「基欧」「卡雅玛雅」「塔科斯」「索基索基」这类都是错的。
- 对照（务必照此）：キュー / チュー → 「啾」；シコシコ → 「撸撸／套弄」；
  ずりずり → 「蹭蹭」；ぐちゅぐちゅ → 「咕啾咕啾」；ドキドキ → 「怦怦跳／心跳加速」；
  ぴゅっ / びゅっ → 「噗／喷」；ぎゅっ → 「抱紧／捏紧」。
- 注意：**角色名是例外**（リリア→莉亚、マヤ→玛雅 这类固定音译要全篇一致），
  判不准就对照术语表，别把名字改成拟声词。

## 纯气声碎片：只译语气词，不要联想（2026-10-14 用户抽检后追加）

整句只有**单假名 + 省略号**的片段（`お…あ…あ…足…`、`お…お…`、`ん…`、`ひ…`）是**没有词义的气声**，
逐字译成中文语气词即可：あ→啊、お→哦／唔、う→呜、ん→嗯、ひ→咿、は→哈。

- ⚠️ **绝不要因为前文出现过某个词就往那个词上靠**。
  实测：前一行是「妈妈们还没回来呢」，模型就把 `お…あ…あ…足…` 译成了「**妈…妈…妈…脚…**」，
  正确应只是「哦…啊…啊…脚…」。
- 判据：整句按「…」切出来的每一段都 ≤1 个字，才算气声串；
  `ん…わかった…`、`ひ…ひらくな…` 里有真词（わかった／ひらく），**不适用**这条，要正常译。

## 人称：补主语 ≠ 改人称（2026-10-14 用户抽检后追加）

日文省略主语要补出来，但**绝不能反过来把原文的人称改掉**——这是两个相反的错误。

- 孩子对母亲说话时的「ママ」译「**妈妈**」，不是「我妈」
  （「我妈」是向别人介绍自己母亲时才用）。
- 「〜なんだ／〜なんです」是在向对方**说明第三方**的事，保持第三人称：
  「バレー部の顧問の先生なんだ」✓「是排球部的顾问老师」✗「我是排球部的顾问老师」。
- 只有原文明确是说话人自称（「私は…」「僕が…」「俺が…」）时，才译「我」。

## 称谓与敬称：按「说话对象」定译法（2026-10-16 补，B1 盲听 N09 暴露）

称谓词靠共现统计学不出来（同一个「先生」在老师/医生/律师语境都出现），
必须按**说话人面对谁**来判断。以下「主译」是该译者语料实测的主流译法
（106743 句对统计），**例外语境**按括号处理。

- **先生（せんせい）→ 主译「老师」**（语料 308 句中 61.4% 译「老师」）。
  例外：当面称呼**医生、律师、议员**等有专业头衔的人时，译「**医生／律师／议员**」
  （日语「先生」是对这些职业的当面尊称，不只老师——查证自日语敬语资料）。
  判据：上下文出现 病院／診察／患者／注射 → 医生；教室／生徒／授業／学校 → 老师。
  注意 `先生` 有时是**戏称**（「おまんこ先生」→「小穴老师」），照字面译即可。
- **さん**：跟在**专名后**时音译保留 + 「桑」——`ミュウさん`→「**Miu桑**」；
  跟在**普通名词后**或单独出现时，按语境译「**你／他／那位**」或省略，**不要**译成「先生／女士」。
- **ちゃん（酱）**：亲昵称呼，译「**小X**」或省略（`さくらちゃん`→「小樱」）；
  跟在爱称后面时保留亲昵感，别译成正式称谓。
- **様（さま）**：
  · `お客様`／`客様` → 「**客人**」；`神様` → 「神」。
  · `旦那様` → 「**老公**（或「老公大人」）」——语料实测，**不是「主人」**。
  · `ご主人様` → 「**主人**」（主仆/BDSM 语境）。
  · 一般 `XX様` 当面称呼 → 「**您**／XX大人」（看语气轻重）。
- **君（くん）**：语料 1533 句中 64.8% 直接译「**你**」，**不要**音译成「君」；
  女生叫男生「XX君」时可保留「XX」（不加后缀）。
- **呼び舍て／あだ名**（直呼其名、绰号）：保持原文的亲疏感，别自作主张加「小」或敬称。

⚠️ 一致性铁律：同一作品内**同一个人物被称呼的方式必须全篇统一**
（不能一处「老师」一处「先生」），出现矛盾时以第一次出现的译法为准。


## 身体部位用词：跟体裁走，别用医学词（2026-10-17 追加，C1 盲听 N29/N31 暴露）

R18 音声作品是**口语色情语境**，身体部位词要按体裁选词，**不要用医学/百科词**。
实测把「おまんこ」译成「**阴道**」——太专业生硬，听感完全不对。

- **おまんこ / まんこ → 「小穴」**（语料既有先例：「おまんこ先生」→「小穴老师」）。
  **不要**译「阴道」「女性生殖器」这类医学词；也别音译成「omango」。
- 其余身体词同理按口语色情语境选词，判不准时**优先选语料里出现过的口语词**。


## 短促感叹 / 口语缩约形：按**实义**译，别糊成「看起来像词」的近义词（2026-10-18 追加）

音声里大量出现**口语缩约形**（形容词/动词被截短、加促音）。这类词模型容易"不认识"，
于是糊成一个看起来像词、实际完全不对的双字近义词。实测踩坑：

- **`くさい` 家族 → 「臭 / 好臭」，绝不译「苦涩」**
  `くっさ` / `くっさい` / `くさーい` / `くさっ` 都是 `くさい`（臭）的**强调口语形**
  （年轻人用法，非正式日语；查证：Wiktionary `くさい` = stinking/smelly，
  HiNative 母语者解释「要强调特别臭时这么说」）。
  `くせえ` / `くっせえ` 是粗俗形；**作后缀**时表「…味／…气」
  （`ガキくせえ`→幼稚、`昭和くせえ`→昭和味），不表气味。
  ⚠️ 实测错译：`くっさ…我慢じる漏れっ放しだったから` → 「**苦涩**…」（应为「好臭…」）。

- **`苦しい` 家族 → 「难受 / 痛苦 / 疼」，绝不译「苦涩」**
  中文「苦涩」是**味觉词**（又苦又涩），日语 `苦しい` 是"难受"。两者毫无关系。
  实测错译三处：`苦しこー`→「好苦涩」、`お笑顔さらして苦しこー`→「笑一笑 苦涩了」、
  `くっさ…`→「苦涩…」。`苦しこ` 是口语缩约（使对方难受的挑逗语），按上下文译
  「让你难受／受不了吧」，**不要**译成形容词。

- 通则：遇到不认识的短促形，**先按最朴素的实义译**（臭/难受/糟了/厉害），
  不要为了"通顺"换成文艺化的双字词。宁可朴素，不要跑偏。


## 我慢汁 族 → 统一「忍耐汁」（2026-10-24 用户拍板）

- **日文**：`我慢汁` / `我慢じる` / `我慢ジェ` / `我慢ジェル` / `ガマンチレ` / `まん汁`
  （后 5 种是 ASR 打坏的写法，语义同一个词）
- **中文**：**统一「忍耐汁」**。用户明确选择保留这个字面直译当**风格词**，
  不要改成「前列腺液」或「爱液」。
- **绝不允许**中文行里残留日文 `我慢汁`（未译）——已全库清零（10 条已修）。
- `忍耐液` 是错字（汁→液），已统一为「忍耐汁」（6 条已修）。
- **例外已解除（2026-10-24 查证）**：`我慢治療` 是 ASR 误识，正确是 `我慢汁`。
  证据：RJ386259 轨 02 同一段音频的另一 ASR 版本产出完整句
  「小種ほどではないものの**我慢汁**も呪いの進行を遅らせられます」；同轨 401s/402s 也全是「我慢汁」；
  「小種ほどではないものの…も」在语法上需要物质名词，不能是「治療」。
  RJ386259 [421.6] 与 RJ302606 [1205.0] 两条已改 ja + zh。
- 「前列腺液」39 条**保持不动**：那些日文多是 ASR 打坏写法（`ガマン汁`/`カーパー`/`こんわん汁`），
  中文猜对了概念，改成「忍耐汁」反而丢精度。


## 不要给不完整的日文片段补戏（2026-10-24，Gemini 对撞发现）

- **现象**：ASR 段常被切成半句（「期末テストの」「勉強するちょうどいい場所がなかったからね」），
  译文容易把「没有地方」读成「可以用来」之类，**补出原文没有的目的/条件**。
- **实例**：`勉強するちょうどいい場所がなかったからね`
  我们译「可以用来准备期末考嘛 没办法。」（错：把 場所がなかった 读成 可以用来）
  正确：「因为正好没有地方学习嘛。」
- **规则**：片段不完整时，**只译已有的信息**，不要替说话人补动机、补条件、补转折。
  读不通就保留半句感（「期末考试的」「那就」），这比补错强。

## そうだね → 「是啊」（2026-10-24）

- `そうだね` = 是啊／对啊；**不要译成「对了」**（「对了」对应 `そういえば` / `あ、そうだ`）。
- 实例：`そうだね` 我们译「对了。」，Gemini 译「对啊。」——Gemini 对。

## ASR 怪词的修正判据：按「语义场」反推，不按读音猜（2026-10-24，用户复核后定）

ASR 出来的词如果在句子里说不通，用下面三条找正确词（至少满足两条才改）：

1. **邻句同义场**：下一句出现同义表达 → 当前怪词是它的误识。
   例：`いやぁ、おはん悪いねー` ← 下句 `おうちお邪魔しちゃって` → 应为 `お邪魔`。
2. **场景常识**：与场景冲突的词换掉。
   例：拜访朋友家问「**象**って誰もいないんだっけ」→ 应是「お母」（妈妈不在家吗）。
3. **同轨重复**：同一轨同一怪词出现 ≥2 次且都说不通 → 系统性误识。
   例：`象` 在同轨出现 2 次（#14/#18），#18 的 `いやー象だけど` 下文是「礼儀として…」→ 应为 `そうだけど`。

⚠️ 反例：Gemini 也会**凭空补词**（给没有 `アナル` 的句子补上），所以这三条只用于**生成候选**，
落地前仍需双源。

### 补充：同型误听会成串（2026-10-24）

发现一处 ASR 误听，**要在同一轨里找同型**——同一条音频的识别错误往往成串。
例：RJ1289104 轨 01 里 `おはん`（应为 お邪魔）与 `おもはん`（应为 うんうん）是同一类
「口语应声/寒暄被听成方言词」的错误，改一处就要查整轨。
