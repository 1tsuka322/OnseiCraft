# 标准样品集（samples）

> 用途：**每次改完代码/语料，跑这一组做自检**，替代 3 小时的全库重跑。
> 建立于 2026-11-07，因为「全库重跑 17 部 / 147 轨」的反馈周期太长，
> 而大多数改动（译法、判据、切分）在少数几条轨上就能暴露。

## 选样标准（用户 2026-11-07 定）

| 维度 | 要求 |
|---|---|
| 题材 | **面要广**——涉及内容越多越能暴露问题 |
| 单轨时长 | **≤15 分钟**；信息量特别高的可放宽到 20 分钟 |
| 总长 | 控制住（当前 12 个样品 / 62 分钟） |
| 音效 | 优先 SE 有效果音版本 |
| 台本 | 有无均可（有的能算 CER） |

**为什么是「每部取 1 轨」**：收藏里最短的整部也有 45 分钟，整部跑一轮 ASR
就要 20+ 分钟，失去自检意义。取单轨后（large-v3 实测 6–9× 实时）：
首次 ASR 约 **12 分钟**，之后只跑 02-06 约 **6 分钟**
（01 产物有 `asr_meta`，参数一致就复用）。

> `IndexError: boolean index did not match`（转 16k wav 后同参数正常）。

### 这组能覆盖什么

- **拟声/气声**（RJ422356 两轨）→ `lexical` 的 content_drop 判据、A8 遮蔽
- **多人声/说话人区分**（RJ422356 环境音、RJ1458584 母女、RJ1364304 三人）→ 人称归属
- **内心独白**（RJ1331975 心声版）→ person_audit 的核心场景
- **情绪极端**（RJ1618225 病娇、RJ1124502 挑衅）→ 语气词、反问句
- **数字/倒计时**（RJ1260535、RJ1458584 罩杯）→ 数字与量词
- **生肉 vs 有台本**（RJ1188708 vs RJ1667609）→ 译法一致性
- **纯音效无台词**（RJ422356）→ 空行/占位符/「…」比例

### 这组覆盖不到的（需要时单独加）

- 长轨（>40 分钟）→ 分块识别、长上下文漂移
- 台本对齐 CER（需要台本原件）
- 极端 ASR 空耳（`ジンポ` 类）——这类靠 errata，不靠样品

## 用法

```bash
# 首次（或改了 01 之后）：全流程
python scripts/selfcheck.py --asr

# 常规（只改 02-06）：跳过 01
python scripts/selfcheck.py

# 只看某一部
python scripts/selfcheck.py --rj RJ1331975
```

输出对比表 + 写到 `internal/docs/experiments/SELFCHECK_<date>.md`。
